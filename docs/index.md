# Barrage

**A language that makes code readable by anyone.**

Barrage is a plain-language format.  
It takes real code and wraps it with clear everyday explanations so that people who have never programmed can still understand what the code is trying to do.

## Why it exists

Code is usually written only for other programmers.  
Barrage exists so that unfinished ideas, prototypes, and real programs can be understood by a much wider group of people — including the people who might want to buy, fund, or use them.

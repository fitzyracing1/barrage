# Contributing to Barrage

Thank you for helping make Barrage better.

## Ways you can contribute

1. **Improve the specification**  
   Suggest clearer wording or new useful sections in `SPEC.md`.

2. **Add examples**  
   Create new complete Barrage documents in the `examples/` folder.  
   Real unfinished code turned into Barrage is especially valuable.

3. **Improve the checker tool**  
   Make `tools/check_barrage.py` stricter, clearer, or more helpful.

4. **Fix mistakes**  
   Typos, unclear explanations, or broken examples.

5. **Use Barrage and give feedback**  
   The most important contribution is simply using the language and telling us what was confusing.

## How to submit changes

- Fork the repository
- Create a new branch
- Make your changes
- Open a pull request with a short description of what you improved

## Style guidelines

- Keep explanations short and concrete
- Always write for a complete non-programmer
- Never hide the original code
- Prefer plain everyday words over technical terms

## Code of Conduct

Be respectful. Barrage exists to make technology more understandable. Contributors should do the same for each other.
